Governed by the CNCF Code of Conduct

A harassment-free community, by design

Cloud Native Austin is dedicated to providing a harassment-free experience for everyone. As an official CNCF Community Group, we strictly adhere to the CNCF Code of Conduct. We expect all organizers, speakers, sponsors, and attendees to help us create a safe, inclusive, and welcoming environment for every skill level.

Read the full CNCF Code of Conduct

Applies to everyone

Organizers, speakers, sponsors, volunteers, and attendees are all expected to uphold the same standard, at every meetup and in the Slack community.

Inclusive by default

We want engineers at every skill level — from first cluster to platform architect — to feel welcome asking questions and sharing what they're building.

Zero tolerance for harassment

Reports are taken seriously and handled promptly by organizers, following the enforcement process defined in the CNCF Code of Conduct.

Reporting a concern

If something doesn't feel right, tell us

You don't need to have a polished report — a quick note is enough for organizers to follow up. You can reach us:

  • By email at organizers@k8sAustin.com
  • By direct message to any organizer in the CNCF Slack
  • In person, by finding any organizer at the event
  • Via the CNCF's own reporting channels, listed in the full Code of Conduct

Every report is confidential

Reports are handled discreetly by organizers and, where needed, escalated to the CNCF's community team. You won't be asked to confront anyone directly.
